- README.txt: this guide and launch checklist.

- Payment instructions displaying the number supplied by the owner: 0725224917.
- Demo sign-in, payment request and membership help screens.

IMPORTANT — NOT A LIVE SERVICE YET
This package is a front-end prototype. It does not yet have:
- a real AI model/API connection;
- user registration, secure login, password reset or database;
- real payment collection or payment verification;
- automatic or admin-driven membership activation;
- protected paid lessons/files on a server;
- actual textbooks or a complete curriculum;
- a registered domain or web hosting.

Do not advertise that it is live or accept payments based only on this demo. The forms do not send data. Do not collect mobile-money PINs or one-time passwords.

Required work before launch
1. Register and configure the igam.com domain if it is available. A name written in this file does not register it.
2. Choose hosting. A static host can publish a preview; a full paid platform needs backend hosting and a database.
3. Implement secure accounts and server-side subscription checks.
4. Integrate an approved payment provider or a documented manual verification process. Confirm transaction references before activating membership.
5. Build an admin dashboard for approving/rejecting payment requests and setting expiry dates.
6. Connect an AI API from the backend only. Never expose API secret keys in browser JavaScript.
7. Use a retrieval/content system based on verified curriculum sources where possible. AI cannot be guaranteed to make zero mistakes; show uncertainty and encourage textbook/teacher checks.
8. Add original/authorized/open-license educational resources. Do not upload copyrighted textbooks without permission.
9. Publish privacy policy, terms of service, refund/cancellation policy, contact information, and secure data-handling procedures.
10. Test that unpaid or expired accounts cannot access paid files directly, including by guessing URLs.

Preview
- Extract the ZIP file.
- Open index.html in a browser.

Publish
- For a preview, upload the file to a static hosting provider.
- For the complete paid platform, use hosting that supports backend code and a database.
- To use www.igam.com, purchase/register the domain and point its DNS to the chosen host, then enable HTTPS.
